Fetch API,
Async & Await

Beginner-Friendly Guide

01

Simple Definition

Fetch API

A JavaScript tool used to get data from somewhere else, usually a server on the internet.

Async & Await

JavaScript features that help you wait for a task to finish without freezing your program.

02

Analogy — You at a Restaurant

❌ Without Async/Await — Blocking

You tell the waiter: "Bring me a pizza."

Then you stand at the counter and do nothing until the pizza arrives. You can't talk. You can't use your phone. You can't do anything else.

✅ With Async/Await — Non-Blocking

You tell the waiter: "Bring me a pizza."

Then you chat with friends, scroll Instagram, drink water. When the pizza arrives, you continue eating.

💡 JavaScript works like this

While waiting for data from the internet, JavaScript can continue doing other work.

03

Why Do We Need Fetch API?

Suppose you open Instagram. The app needs to get posts, comments, likes, and your user profile. These are not stored inside your browser — Instagram's servers have them.

So the browser asks: "Hey server, send me the posts."
The tool used for this request is often Fetch API.

🖥️

What is a Server?

A giant computer that stores information. Instagram servers store posts. Spotify servers store songs. Google Maps servers store locations. Your browser asks the server for data — the server sends data back.

04

Fetch & the Promise Problem

A basic fetch request:

fetch("https://api.example.com/users");

This means: "Go to this address and bring me the data."

But getting data takes time — maybe 1, 2, or 5 seconds. JavaScript cannot instantly get the answer. So Fetch returns something called a Promise.

🍕 What is a Promise?

You order pizza. Immediately after ordering, the pizza is not ready yet. You only have a promise that it will arrive.

Same thing with fetch — the data isn't here yet. You only have a promise.

const data = fetch(url);

console.log(data); // Promise { <pending> }
05

Enter Async and Await

Async and Await make working with promises easier.

⚙️

async

When you put async before a function, you are telling JavaScript: "This function may need to wait for something."

async function getUser() {
  // this function may need to wait
}
⏳

await

await means: "Pause this function until the result arrives."

const response = await fetch(url);

// Send request → Wait for response → Continue
06

How Fetch Actually Works

async function getUsers() {
  const response = await fetch(
    "https://jsonplaceholder.typicode.com/users"
  );

  const users = await response.json();

  console.log(users);
}
  • 1
    await fetch(url) — Browser sends request and waits.
    Browser
    ──────→
    Server
    "Send users"
  • 2
    Server responds — Data arrives and is stored inside response.
    Server
    ──────→
    Browser
    "Here are users"
  • 3
    await response.json() — The response arrives as raw data. json() converts it into a JavaScript object/array.
  • 4
    console.log(users) — Now you can use the data.

07

Why Not Just Use Fetch Alone?

😵 With .then() — Harder to read
fetch(url)
  .then(res => res.json())
  .then(data => {
    console.log(data);
  });
✅ With Async/Await — Clean & clear
const res  = await fetch(url);
const data = await res.json();

console.log(data);
💡 Key benefit

Async/Await looks like normal top-to-bottom code — much easier to understand.

08

Common Confusions

Confusion 1 — Does Await Stop JavaScript?

No. It only pauses the current async function. The rest of JavaScript can continue running.

Confusion 2 — Is Fetch the Same as Async/Await?

No. Fetch is used to request data. Async/Await is used to handle the waiting.

Think: Fetch = ordering pizza. Await = waiting for pizza.

Confusion 3 — Does Fetch Return Data Directly?

No. Fetch returns a Promise, not the data. Many beginners expect const data = fetch(url) to work — but it gives Promise <pending>. You must await it.

Confusion 4 — Why Use Await Twice?

Because both operations take time:

const response = await fetch(url);    // wait for server response
const data     = await response.json(); // wait for JSON conversion

Simple Summary

  • 1Fetch API is used to get data from a server.
  • 2Fetch returns a Promise, not the actual data.
  • 3async tells JavaScript that a function may need to wait.
  • 4await waits for a Promise to finish.
  • 5await fetch() waits for the server response.
  • 6await response.json() waits for JSON conversion.
  • 7Fetch and Async/Await are commonly used together.
